# instagram-video-download

An [Agent Skill](https://skills.sh) for saving Instagram reels, IGTV, and post videos with `yt-dlp`.

```
npx skills add <your-github-user>/instagram-video-download
```

## What it does

- **Download** — reels, IGTV, post videos in best quality
- **Audio extract** — MP3 from any Instagram video
- **Batch** — whole profiles, URL lists
- **Ethics** — copyright and ToS

See [`SKILL.md`](./SKILL.md) for the full instructions.
